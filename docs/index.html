Premise

Accumulating context is not the same as learning. Longer prompts and retrieved snippets can look like memory while the model still fails the same class of bug.

BrainDiff holds the coding agent constant and varies only what it is allowed to remember — then scores with the repository’s own tests, not an LLM judge.

Scoring pipeline

01

Parent commit

Historical parent of the fix — the buggy tree.

02

git archive

Materialize the tree with no .git — no answer in history.

03

Overlay tests

Copy only the fix’s test files onto the parent tree.

04

Gate: confirm they fail

Control run: parent must fail the overlaid tests before any agent starts.

05

Agent attempts

Same agent, one memory condition, budgeted tool loop.

06

Re-run and diff

Score with the same tests; compare per-test outcomes and capture the patch.
